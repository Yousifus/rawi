Settings

The switches in "Right away" apply as you click them. Everything else waits for the Save button at the bottom.

Right away

On

Every line is saved on this computer, in transcripts.jsonl in the rawi folder. History, Sky, Usage and Patterns are built from it.

Off

Nothing is kept after it is pasted. The stats pages stay empty.

Cleanup optional

Cleanup sends each line to a small language model running on your own computer, which takes out filler words like "umm" and "يعني" and adds punctuation. It needs an OpenAI-compatible model server running on this computer, set in config.json (the README has the details). Without it, rawi pastes exactly what it heard, which is what most people want.
